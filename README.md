---

## 📌 Project Overview

**InAmigos Foundation** is a Section 8 registered non-profit organization founded on **September 23, 2020**, by **Mr. Govind Shukla** (Founder & CEO), headquartered in Chhattisgarh, India. Operating across **28 states** with over **200 volunteers** and impacting **50,000+ beneficiaries**, the foundation works towards food security, child education, animal welfare, women empowerment, environmental sustainability, and youth skill development.

This repository contains a full multi-page web template designed with clean typography, smooth CSS transitions, interactive JavaScript components, hover effects, and modal dialogs.

---

## ✨ Key Features & Highlights

* **🎨 Modern UI & Color Palette**: Styled using Google Fonts (*Montserrat* and *Poppins*) and an Emerald Green theme (`#00C885`) matching the official NGO brand.
* **📱 Fully Responsive**: Seamless experience on desktops, tablets, and mobile devices with a custom sliding drawer menu.
* **🖼️ Dynamic Hero Slider**: Auto-playing slideshow with manual controls highlighting key initiatives (*Sewa*, *Bachpanshala*, *Udaan*, *Jeev*, *Prakriti*).
* **📊 Animated Impact Counters**: Live counting statistics triggered upon scrolling into view (**200 Volunteers**, **28 States**, **6 Causes**, **50,000+ Beneficiaries**).
* **💡 6 Core Project Highlights**:
  1. **Project Sewa**: Food distribution, grocery kits & blanket drives.
  2. **Project Bachpanshala**: Free child education, evening classes & school kits.
  3. **Project Jeev**: Stray animal rescue, medical treatment & daily feeding.
  4. **Project Udaan**: Women skill development, tailoring & financial independence.
  5. **Project Prakriti**: Tree plantation drives & ecological awareness.
  6. **Project Vikas**: Youth employability & vocational internship drives (#InAmigos).
* **🤝 Interactive Modals**: Dedicated popup dialogs for *Donate Now* (with 80G tax exemption details) and *Volunteer Applications*.
* **🖼️ Filterable Photo Gallery**: Instant client-side category filtering for photo archives.
* **📜 Official Certifications Showcase**: Highlights legal standings including **Section 8 Licensing**, **80G & 12A Certifications**, **CSR-1 Registration**, **NITI Aayog Alignment**, and **IAF ISO 9001:2015 Quality Management**.

## 🚀 Getting Started

### Prerequisites
No special framework or build tools are required. Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) is sufficient.

### Installation & Usage

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/inamigos-awareness-webpage.git
   ```

2. **Navigate to the Project Folder**:
   ```bash
   cd inamigos-awareness-webpage
   ```

3. **Run the Website**:
   * Double-click `index.html` to view it in your browser.
   * Alternatively, run a lightweight local server:
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your web browser.
